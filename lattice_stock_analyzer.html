What is a Lattice?

A partially ordered set (poset) where every pair of elements has a unique greatest lower bound (Meet ∧) and a unique least upper bound (Join ∨). Stocks form a lattice based on financial criteria.

Core Operations

Meet (∧): Finds the greatest lower bound — the shared baseline quality between two stocks.

Join (∨): Finds the least upper bound — minimum attributes to cover both stocks' potential.

Formal Concept Analysis

Maps Objects (Stocks) to Attributes (Financial metrics) using a triple (G, M, I). Produces a Hasse diagram grouping stocks into "concepts" based on shared strengths.

Mathematical Theory
Formal definitions, axioms, and operations behind the lattice framework
Definition: Partial Order

Poset (L, ≤)

A lattice is a partially ordered set where every pair of elements has both a Meet and a Join. Our set L represents the collection of stocks from the KSE-100 index.

Three Axioms
  • P1
    Reflexivity
    Every stock is at least as good as itself: a ≤ a
  • P2
    Antisymmetry
    If a ≤ b and b ≤ a, then a = b. Two stocks with identical metrics are the same lattice element: a ≤ b ∧ b ≤ a ⟹ a = b
  • P3
    Transitivity
    If A dominates B, and B dominates C, then A dominates C: a ≤ b ∧ b ≤ c ⟹ a ≤ c
Formal Concept Analysis (FCA)

Formal Context (G, M, I)

G — Set of objects (Stocks)
M — Set of attributes (Financial metrics: ROE, D/E, P/E, Dividend, Growth)
I ⊆ G × M — Incidence relation: stock g has attribute m

Concept Formation

A formal concept is a pair (A, B) where A ⊆ G and B ⊆ M such that B is exactly the set of attributes shared by all stocks in A, and A is exactly the set of stocks that have all attributes in B.

concept = (A, B) where A' = B and B' = A
Core Operations

Meet ∧ — Greatest Lower Bound

The Meet of two stocks finds the stock (or virtual stock) that represents the best achievable baseline both stocks surpass. Analogous to HCF (Greatest Common Divisor).

a ∧ b = max { x ∈ L | x ≤ a and x ≤ b }

In practice: takes the minimum value for each metric (conservative bound).

Join ∨ — Least Upper Bound

The Join of two stocks identifies the minimum requirements to cover the potential of both. Analogous to LCM (Least Common Multiple).

a ∨ b = min { x ∈ L | a ≤ x and b ≤ x }

In practice: takes the maximum value for each metric (optimistic bound).

HCF/LCM Analogy

Consider L = {1, 2, 3, 6} under divisibility relation:

MEET (∧) ≡ HCF
2 ∧ 3 = 1
HCF(2,3) = 1
JOIN (∨) ≡ LCM
2 ∨ 3 = 6
LCM(2,3) = 6
Lattice Properties Used
  • L1
    Commutativity
    a∧b = b∧a,   a∨b = b∨a
  • L2
    Associativity
    a∧(b∧c) = (a∧b)∧c
  • L3
    Absorption
    a∧(a∨b) = a
  • L4
    Idempotency
    a∧a = a,   a∨a = a
